📄 README.md - Portal Berita

📌 Deskripsi

Portal Berita adalah aplikasi fullstack yang terdiri dari dashboard admin dan tampilan user untuk mengelola serta menampilkan artikel berita. Admin dapat menambah berita, kategori, dan mengelola komentar. Tampilan user menyediakan halaman beranda, detail berita, dan pencarian berdasarkan kategori.

🧰 Teknologi

Frontend: React.js + Tailwind CSS

Backend: Node.js + Express.js

Database: PostgreSQL + Sequelize ORM

Auth: JSON Web Token (JWT)

Image Hosting: Cloudinary

🚀 Cara Menjalankan

Backend

cd backend
npm install
cp .env.example .env
# edit isi .env
npm run dev

Frontend

cd frontend
npm install
npm run dev
